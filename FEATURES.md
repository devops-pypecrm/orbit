## Marketing-team features worth adding (Asana, Monday, Trello, Notion style)
- **Content calendar** (month view of due dates) — highest value for marketing
- **Approval status** (Review → Approved) with a reviewer field
- **Campaign grouping** above projects, plus **task templates** (e.g. "Blog post" checklist)
- **Request forms** so other teams can submit work into a project
- **Asset attachments** with previews for creatives
- **Workload view** (tasks per person per week)

Suggested next 3: **subtasks + labels**, **calendar view**, **email notifications**.
